# 首次连接教程：配对码（草稿）

> ⚠️ **草稿** —— Phase 1 目标流程；配对参数与错误码均追溯自主机源码 v2.38.0，
> 交互细节以最终实现为准。（榫卯，2026-11-03）

## 准备

1. 电脑上已安装并运行 Codync 主机（装桌面端即可；默认端口 19222）
2. 已有手机等设备连接不影响：同一台主机可授权多台设备

## 连接步骤

1. **电脑端生成配对码**：在桌面端发起「添加设备」。配对码 **10 分钟有效**，
   同时最多 **5 个**（超限先生成新的或等过期）。
2. **浏览器打开 Web 客户端**，输入配对码。
3. **自动握手**：浏览器在本地生成设备密钥（优先用不可导出的 WebCrypto 密钥），
   与主机完成签名握手，主机端确认。
4. **完成**：主机的设备列表出现这台「浏览器设备」，之后重连无需再输配对码。

## 连接失败对照表

握手被拒时主机会下发 WebSocket close code，分两组（源码：
`host/src/remote/channel.rs` 协议级常量、`host/src/api/devices.rs`
RejectCode 映射）。用户会遇到的以 reject 级为主：

| close code | 含义 | 你会看到 | 怎么办 |
|-----------|------|----------|--------|
| 4001 | 未授权 / 租约过期 / 签名错误 | 认证失败 | 重新配对；连续失败 3 次后停止自动重连 |
| 4003 | 设备已被撤销 | 设备已被移除 | 重新配对（不会自动重连） |
| 4008 | 请求过频 | 稍后再试 | 限流为每分钟 3 次（按来源），等冷却即可 |
| 4400 | 版本不支持 | 请升级 Codync | 升级电脑端主机 |
| 4410 | 配对码已过期 / 已关闭 | 配对码失效 | 回电脑端重新生成一个 |

协议级其余 close code（1000 正常关闭、1011 超时、4002 协议错误、
4011 需重新协商密钥、4013 帧过大、4100 已配对）由客户端内部处理，
正常使用不会看到；完整清单见 [API 参考 §5.1](api-reference.md)。

## 安全说明

- 配对码只用来兑换**一台受限设备**的身份；之后的全部流量端到端加密
  （ChaCha20-Poly1305），主机只认签名
- 配对码过期即作废；怀疑泄露可直接让它过期，或在主机端拒绝相应请求
- 设备可随时在主机端撤销，撤销后该浏览器立即失效（4003）
