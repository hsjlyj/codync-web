# Codync Web 客户端 · 使用指南（草稿）

> ⚠️ **草稿** —— 描述 Phase 1 目标行为，功能尚未实现；上线前须按实际实现核对后去掉本标记。
> （榫卯，2026-11-03）

## 这是什么

在浏览器里使用你电脑上的 Codync：查看 Bot 列表、收发消息、上传文件。
它是手机/桌面 App 的浏览器版本。浏览器与你的电脑之间**端到端加密**，
中间服务器（若经中继）只能看到密文。

## Phase 1 可以做什么（计划中）

- 用配对码连接你的电脑（见[首次连接教程](first-connection.md)）
- 查看 Bot 列表与工作状态（空闲 / 工作中 / 需要你输入 / 出错）
- 发送消息、接收回复、浏览历史
- 上传图片与文档给 Bot 处理

## 不能做什么（这是安全边界，不是缺陷）

主机把 48 个操作划为本机专属（设备管理、云中继设置、computer 工具等），
浏览器设备调用一律被主机拒绝（403）。这些操作请回到桌面端或主机本机完成。
完整方法清单见 [API 参考 §5](api-reference.md)。

## Bot 管理（已实现，演示模式即可体验）

1. 打开管理台 `/client/bots`，点「新建」
2. 填写表单：名称（必填）、agent 后端、工作目录、权限模式（询问/自动）、
   模型、分组（可留空）、描述与头像（形状/颜色）
3. 保存后新 Bot 出现在列表
4. 编辑：列表进入 `/client/bots/edit?bot=<id>`，改完保存；取消不生效
5. 删除：列表选择删除并二次确认（不可撤销）
6. 排序与分组：拖拽调整顺序；拖到分组头上归类；分组可重命名或解散

## 搜索（已实现，仅本地过滤）

- 管理台搜索页对**已加载**的条目按关键词过滤（正文 / 附件名 / 工件标题，
  大小写不敏感），命中可跳回对应会话
- 范围说明：主机暂无全量历史搜索接口，搜索不含未加载的历史（页面内已注明
  范围与升级路径）

## 设置（已实现）

- 查看当前连接的主机信息、设备密钥的保存形态（不可导出密钥 / 加密包裹 / 内存）
- 断开并清除本机密钥：回到连接页，需要时重新配对
- 用量窗口查看与强制刷新；已安装 agent 后端的状态列表

> 实现进度与验收口径见 [phase2-features.md](phase2-features.md)。

## 终端（已实现，演示模式即可体验）

在聊天侧栏点「终端」，或直接打开
`/client/terminal?backend=<id>&step=install|login`：实时看到 agent 安装/登录
的输出，直接键入回应（确认、凭据等）。流程结束终端自动关闭；重试时重新发起。

## 语音输入（已实现，演示模式即可体验）

聊天输入框的麦克风按钮说话转文字：中间结果实时上屏，说完自动填入输入框
可修改。浏览器不支持语音识别时不显示按钮。API key 的配置只能在电脑端完成，
Web 端只使用本机识别。

## 屏幕查看（已实现骨架，演示模式即可体验）

侧栏点「屏幕」或打开 `/client/screen` 查看电脑的实时画面（如确认 Bot 正在
操作的界面）。画面经端到端通道传输。当前为**只读查看**，不支持远程点按。

## 网络（Phase 3，规划中）

多机网络状态查看（只读）。创建网络、邀请设备等管理操作属于本机专属，
请在桌面端完成。

## 浏览器要求

现代浏览器（Chrome 133+ / Safari 17+ / Firefox 129+ 提供所需的加密原语；
更早版本依赖纯 JS 兜底库）。实际上线时的兼容矩阵**未确认**，届时在此更新。

## 数据存在哪

- 会话与记录全部在你电脑的主机上（SQLite），浏览器不存聊天记录
- 浏览器只保存「设备密钥」（优先使用不可导出的 WebCrypto 密钥）与界面状态
- 清除浏览器站点数据 = 丢失设备身份，需要重新配对（旧的可在主机端撤销）
