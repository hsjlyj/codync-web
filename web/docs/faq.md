## 连接与安全

**Q：连接时提示 close 4400？**
两种可能：主机版本太旧（不支持当前协议，或其白名单还不认识 `web` 平台——
客户端会自动回退重试一次，连续失败说明主机确实太旧），或主机没有云签发的
设备证书（配对要求主机开启云且已登录，`certificate.rs`）。先升级主机，
再确认云状态；Web 端云证书流程在 Phase 2，当前可用连接页的证书粘贴栏实测，
无云/私有部署可用 `CODYNC_DEVICE_CERT_KEY` 自签证书（见 ADR-001 后果节）。

**Q：为什么要配对码？直接把主机 token 填进网页不行吗？**
不行。主机 token 是本机完全控制凭证（仅限 loopback 使用），交给网页等于把
整台电脑交出去。配对码只兑换一台受限设备身份：主机对设备可调的方法做了
硬性限制（151 个中 103 个，敏感操作直接 403），且设备可随时撤销。

**Q：经过中继服务器时，能看到我的消息吗？**
不能。浏览器与主机之间是端到端加密通道（ChaCha20-Poly1305），
中继只转发密文，也看不到配对码兑换过程。

**Q：为什么有些功能 Web 端没有？**
主机把 48 个操作划为本机专属（设备管理、云设置、computer 工具等），
对浏览器设备一律拒绝——这是主机的安全边界，不是 Web 端的 bug。
请回桌面端操作。

**Q：换浏览器 / 清了浏览器数据会怎样？**
设备密钥丢失，需要重新配对一次；旧设备身份建议在主机端撤销。

## 使用

**Q：聊天记录存在哪？**
在你电脑的主机上（SQLite）。浏览器不持久保存聊天记录，每次连接从主机同步。

**Q：多台电脑能用吗？**
主机侧有多机网络能力，但产品目前以一台电脑为目标；Web 端是否开放多机管理
**未确认**（Phase 3 议题）。

**Q：消息发不出去 / 一直转圈？**
先看连接状态：顶栏断开时客户端会自动重连；若提示 4001/4003/4410 等，
按[首次连接教程](first-connection.md)的对照表处理。重连策略细节以实现为准。
